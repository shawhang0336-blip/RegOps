# EAST（监管数据标准化规范）

## 结论

现行版本 EAST 5.0 的规范正文、数据结构、检核规则全文，**都没有公开原件**。本目录只有：检核规则的第三方 OCR 试读片段，以及三份数据治理类的上位文件（其中一份是监管端内部办法）。

## 版本与文号

- 《中国银保监会银行业金融机构监管数据标准化规范（2021 版）》，即 EAST 5.0，2022-01-30 下发，2022-05 起首次报送。文号媒体口径为银保监办发〔2022〕7 号，未见官方原页。
- 总局和 36 个省级监管局的规范性文件栏目都已筛过，没有这份规范，也没有它的检核规则全文。分局站点只有分局自己制定的统计管理制度（见 `../08_派出机构_监管统计管理制度/`），其中东营分局的考核办法附件带了《非现场监管统计数据质量考核标准》《新版客户风险统计报表数据质量考核标准》，是分局对下考核用的口径，不是 EAST 检核规则。
- 配套《监管标准化数据检核规则（2021 版）》，共 3283 条：强校验 2286 条、非强校验 997 条。
- 规模：11 个监管主题域、70 张数据表、1838 个数据项。其中 62 张由银行报送，8 张理财业务表由理财登记中心总对总采集。
- 主题域（第三方文章口径）：公共信息、客户信息、会计记账信息、卡片信息、各项贷款、表外授信业务、表内外担保信息、信贷管理信息、信用卡、资金交易信息、理财业务。

> 注意：同一篇第三方文章给出的各域张数（6/5/12/3/13/5/3/5/4/5/8）合计是 69，与它自述的 70 张不一致。以原件为准。
