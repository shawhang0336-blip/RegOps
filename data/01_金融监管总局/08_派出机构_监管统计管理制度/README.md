# 派出机构监管统计管理制度

## 这是什么

36 个省级监管局（含大连、宁波、厦门、青岛、深圳 5 个计划单列市局）官网「规范性文件」栏目全量 1107 条标题逐条筛查，命中 55 份与监管统计、数据、报表有关的文件，全部下载。

**这些是分局自己制定、对辖内机构用的统计管理制度，不是上级下发的 EAST / 1104 / 一表通报送规范。** 1104 报表制度、EAST 规范在 36 个栏目里都没有。

## 注意

- 效力状态没有逐份核验：2020 年及以后的 28 份，2015 年及以前的 17 份，后者可能已废止或被修订。做依据前先看发文日期，必要时向对应监管局确认。
- 2004–2014 年的文件（北京市场准入非现场验收、涉诉客户信息报送、早期统计考核评比办法等）参考价值有限，一并留着。
