# 监管报送文件库

整理日期：2026-11-27。范围：**聚焦商业银行监管报送体系**（金融监管总局、人民银行、外汇局），以及银行报表口径直接依赖的国家分类标准（已清理信托、保险、融资担保/融资租赁、券商风控、财务公司/汽金/消金/金租等非银行机构资料）。

**先说结论：EAST 5.0、1104 报表制度、一表通采集标准这三套核心规范，原件都不公开，网上拿不到。** 清理非银行资料后，本库聚焦商业银行实际保留：

1. **金融监管总局银行业上位制度**官方原件（商业银行资本、流动性、大额风险暴露、贷款风险分类、数据治理、数据安全、理财/托管等，逐份带文号和原页链接）；
2. **省级监管局银行业统计管理制度**（银行业统计考核/评价/积分办法、数据质量问题认定处理办法、客户风险统计数据报送规程、上海自贸区银行业监测报表制度等）；
3. **公开的银行业报表模板与多文件混装测试包**：上海自贸区 8 张银行业监测 `.xls` 表样及 7 份 `.doc` 填报说明、投贷联动监测统计表 `.xls`，以及 `_samples/` 下的一表通 2.0 / EAST 5.0 ZIP / 1104 G01 / SAFE 多文件混装测试样本；
4. **两份第三方片段**：EAST 检核规则 OCR 前 39 页、1104 全部 297 张报表的目录及版本号 CSV；
5. **人民银行、国家外汇局与国家统计局公开原件**：人行 JR/T 0134-2016 存款分类编码、绿色金融支持项目目录、反洗钱管理办法；外汇局 1.3 版全文、汇发〔2025〕22 号对外金融资产负债制度及 2024 核查规则全套 4 份 PDF、国际收支申报指引与公开代码表；国家统计局 GB/T 4754-2017 国民经济行业分类码表。

逐文件清单见 [`_文件清单.md`](./_文件清单.md)，来源 URL 在 `_manifest_nfra.json`、`_manifest_branch.json`、`_manifest_other.json`。当前清理后纯银行语料共 **222 个文件、约 26MB**（其中可解析二进制/归档原件 118 份，`.gitignore` 已忽略二进制原件）。

## 三、文件性质怎么读

- `*_正文.md`：官网公开正文由 HTML 转写，保留段落和表格，**公式、图、页眉附件会丢**，以原页和附件为准。文件头写明文号、日期、官方原页。
- 附件（pdf / doc / docx / xls / xlsx）：官网原始文件，未改动。
- 文件名前缀是发布日期，`〔〕` 内是文号；状态标在 `_文件清单.md` 的「状态」列（现行 / 历史 / 上位指引）。
- 两份第三方件单独标了「第三方」字样，不能作为合规依据。

## 六、维护

- 总局官网抓取方式：列表接口 `/cbircweb/DocInfo/SelectDocByItemIdAndChild?itemId=861&pageIndex=N&pageSize=20`，单篇 `/cbircweb/DocInfo/SelectByDocId?docId=X`，附件路径在返回的 `attachmentInfoVOList[].urlOtherName`。连续请求约 40 次后 `/cbircweb/` 会被 403（持续数十分钟以上）；此时静态通道 `/cn/static/data/<同名路径>/data_<参数>.json` 仍可用，但只有被访问过的条目有缓存；繁体镜像 `big5.nfra.gov.cn` 的动态接口不受影响，返回繁体，需转简体。
- 36 个省级监管局「规范性文件」栏目的 itemId 是连续的 4177–4212（西藏→深圳）。分局「公开目录」栏目是数万条行政许可批复，没有检索价值。
- 原创力文档 `max.book118.com/try_down/<文档id>.pdf` 只给“可阅读页数的一半”，且多为 OCR 扫描件。
